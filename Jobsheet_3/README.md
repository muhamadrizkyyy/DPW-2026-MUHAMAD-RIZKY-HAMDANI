# 📘 Jobsheet 3 — Responsive Design

> **Sub-CPMK:** Membangun tampilan responsif.

---

## 🎯 Deskripsi

**Jobsheet 3** berfokus pada penerapan **Responsive Design** untuk mengembangkan tampilan website dari Jobsheet 2.

Pada jobsheet ini, website dikembangkan agar memiliki tampilan yang **responsif dan dapat menyesuaikan ukuran layar**, baik pada perangkat desktop maupun perangkat mobile.

---

## 🔄 Perubahan dari Jobsheet 2

Beberapa perubahan yang dilakukan pada Jobsheet 3 antara lain:

### 1. 🍔 Penambahan Elemen Hamburger pada Navbar
### 2. 📊 Penambahan `div class="table-responsive"
### 3. 📱 Penerapan Media Query
### 4. 📱 Penambahan Meta Viewport

## ✨ Hasil yang Diharapkan

Setelah menyelesaikan **Jobsheet 3**, website diharapkan memiliki:

* ✅ Tampilan **responsive** pada berbagai ukuran layar.
* ✅ Navbar yang dapat menyesuaikan tampilan pada perangkat mobile.
* ✅ Hamburger menu pada tampilan layar kecil.
* ✅ Tabel yang tetap dapat digunakan pada layar kecil.
* ✅ Grid card yang dapat menyesuaikan ukuran layar.
* ✅ Tampilan website yang lebih rapi dan nyaman digunakan.

---

## 🚀 Cara Menjalankan

Buka file **`index.html`** menggunakan browser.

Untuk menguji tampilan responsive, ubah ukuran jendela browser atau gunakan fitur **Developer Tools → Device Toolbar** pada browser.

---

## 🎓 Kesimpulan

Pada **Jobsheet 3 — Responsive Design**, dilakukan pengembangan website dengan menerapkan konsep **Responsive Web Design**.

Penerapan **hamburger navigation, `table-responsive`, Media Query, dan meta viewport** membuat website dapat menyesuaikan tampilannya pada berbagai ukuran layar sehingga lebih **fleksibel, rapi, dan nyaman digunakan**. 📱💻
